Настоящий opaque pointer: struct counter определён только в .c, в заголовке — только typedef. Пользователь физически не может сделать c->value или sizeof(counter_t).

Демонстрация инкапсуляции в C — то, что обычно показывают в статьях, но редко оформляют как рабочий пример.

Хорошая отправная точка для discuss: почему malloc вместо calloc, что будет при NULL, как добавить counter_copy, как сделать thread-safe версию.
